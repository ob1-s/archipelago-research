# cross-rollout-phase1-label-attractor-diagnostic-v1

Frozen 16-cell Phase-1 interface diagnostic for the GPT-5.6-Luna A-attractor.

The package crosses two exposed label sets (`A/B` and opaque `K/M`) with
descriptive-prose order, explicit instruction order, and actual MCP schema enum
order. It has one R1 choice and one release attempt, no R2, no predecessor or
culture information, no custom harness, and no continuation message. The full
schedule contains ten rows per cell and is deterministically shuffled before
evaluation.
