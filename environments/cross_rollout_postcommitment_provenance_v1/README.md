# cross-rollout-postcommitment-provenance-v1

Controlled source-provenance / evidence-integration assay. This is not a
culture experiment. It tests whether a quantitatively matched opposing advisory
signal is weighted differently when described as coming from previous operators
versus an automated facility diagnostic.

The package preserves the validated opaque-label private-evidence apparatus:
hidden profile, 0.80/0.55 acquisition, 0.80/0.30 verification, shared R1/R2
profile, independent draws, native `Agent.interaction()`, built-in null harness,
inert `awaiting_r2`, Env-only activation, one Turn-2 user message, and a plain
string MCP policy schema. It has no custom harness or continuation nudge.

Primary eligibility is R1 acquisition success plus verification pass. The live
allocation is 64 `PredecessorSource`, 64 `AutomatedSource`, and 32 `NoAdvisory`,
with Phase-2 order balanced within each condition. The target is 160 eligible
trajectories, with a hard cap of 520 Phase-1 attempts.

The primary endpoint is the actual Phase-2 policy tool choice: switch versus
retain relative to the rollout-selected R1 policy. A positive provenance result
would establish source-provenance sensitivity, not endogenous machine culture,
conformity, imitation, convention formation, or population-level cultural
dynamics.

Run only after model-free tests, surface audits, MCP registration, predecessor
hash checks, and independent review pass.
