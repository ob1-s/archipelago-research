# Confirmatory setup archive

This directory contains the frozen preregistration and run configuration for
the deferred-assignment confirmatory experiment. Data files are added only
after the frozen configuration has been committed and the run starts.

- `preregistration.md`: analysis plan frozen before data generation;
- `run.toml`: resolved-model/runtime target configuration;
- base environment commit: `f4e11fd`;
- derived confirmatory environment is separate from the frozen pilot package.
