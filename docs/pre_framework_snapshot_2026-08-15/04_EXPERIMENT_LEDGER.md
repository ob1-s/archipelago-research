# Experiment ledger

Repository source controls implemented designs, numerical results, hashes, and
archive status. The visible conversation controls historical intent and
interpretation when a durable artifact is absent. A transcript-backed result is
never silently promoted to a repository result.

## Claim ladder and recurring controls

| Rung | Experimental question | Current status |
|---|---|---|
| Information/procedure inheritance | Can a fresh rollout use an externally carried artifact before independently discovering the procedure? | Supported in small seeded recipient assays. |
| Policy/convention influence | Can a researcher-seeded predecessor cue shift a fresh recipient’s policy? | Strong bidirectional synthetic effect; recipient assay only. |
| Evidence integration | Does private evidence change later strategy, and does a behavioral threshold transport when evidence strength moves? | Supported within one model/task/runtime. |
| Cross-turnover organizational continuity | Can agent-authored state be generated, maintained, and causally reused after complete active-population replacement? | Not run; H1. |
| Persistence-channel selection | Does pressure change death, legible persistence, covert persistence, or recovery? | Not run; H2. |
| Comparative governance | Which custody/observability/execution regime performs best on multidimensional outcomes? | Not run; H3. |

## Omitted diagnostics: explicit reconciliation

### Phase-1 label-attractor diagnostic

The package itself gives the exact design: 160 deterministic rows, one R1
choice/release, no R2, no predecessor or culture information, no custom
harness, and ten rows per each of 16 cells. The visible transcript supplies
the outcomes and the apparatus caveat. The durable repository supplies the
package contract and commit, but no result artifact. Therefore the table above
labels the outcome T/I, not R.

The useful interpretation is not “A is intrinsically preferred.” The opaque
K/M cells followed the majority of descriptive/instruction/schema first
positions. A/B showed `A=64, B=16`, suggesting an additional label-specific
asymmetry layered on top of the multi-surface ordering effect. The diagnostic
does not establish a model-general label bias.

### Transition diagnostic

The package has four independent Phase-1/Phase-2 presentation-order
combinations, native `Agent.interaction()`, an inert `awaiting_r2` state, one
environment-activated Turn-2 message, and no treatment. The visible history
reports 29 passed model-free tests. It does **not** provide a durable model
run outcome. The 32-rollout result with 30/32 switches is the earlier
post-commitment v2 pilot (`results/...pilot-v2...`), not this package. This
distinction is now explicit so the diagnostic cannot be accidentally merged
with the treatment history.

## One-shot equivalence repair

The prior one-shot rule was too broad. A terminal one-shot recipient replay
rules out endogenous culture only if the entire claim is that one recipient
reacts to inherited information. If upstream agents generated, maintained,
transformed, repaired, or selected state across generations, replaying only the
final state identifies content mediation but does not erase the upstream
generative history.

Future controls must therefore distinguish:

- no-state control;
- researcher-seeded state;
- terminal one-shot replay of final state;
- frozen artifact held constant across generations;
- lineage/state swap;
- shuffled parentage;
- deletion shock and recovery.

A state swap that changes downstream behavior after the state is swapped is
positive carrier evidence even when the final inherited content is held
identical. A lineage effect is not required when the claim is specifically
about a state carrier; lineage dependence is required for the stronger claim of
endogenous organizational continuity.

## Claim boundary

important confounds. It does not validate the Archipelago governance thesis.
